# v1.3.0

## Summary

This release introduces configurable client options, improves debug logging, updates the README to reflect the current API, and adds project documentation.

## Breaking Changes

- **`Connect` signature changed**: Now requires a third parameter `*ClientOptions` (pass `nil` for defaults).

```go
// Before (v1.2.x)
mq, err := mongocc.Connect("mongodb://localhost:27017", "my_db")

// After (v1.3.0)
mq, err := mongocc.Connect("mongodb://localhost:27017", "my_db", &mongocc.ClientOptions{
    Debug: true,
})
// Or with nil for defaults:
mq, err := mongocc.Connect("mongodb://localhost:27017", "my_db", nil)
```

## Changes

### Configurable Debug Mode

Debug logging is now controlled via `ClientOptions.Debug` instead of being hardcoded to `true`. Passing `nil` options defaults to `Debug: false`.

### Debug Log Prefix

All debug log messages now use the `[Mongocc Log]` prefix instead of `[LOG]` for easier filtering in applications with multiple logging sources.

### Documentation

- **README**: Updated usage example to match the current API. Removed references to the non-existent `MongoDataStore` struct.
- **LICENSE**: Updated copyright to 2025-2026.
- **docs/project-review.md**: Technical review with architecture, full API reference, and improvement recommendations.
- **docs/project-overview.md**: Non-technical overview for stakeholders.

## Known Issues

- `MongoFunctions` interface does not include `FindOneAndUpdate`, `InsertMany`, or `GetCollection`.
- Standalone `CheckMongoError` function is deprecated but still exported.
- No test coverage.
